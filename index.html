About this tool

Not an official Microsoft deliverable. This deck is assembled from the public Microsoft 365 Roadmap and Message Center feeds. It does not use ESXP, does not require a dispatch, and is not the official PRAI deck. Check anything customer-facing against the official source before you send it.

  • New means the item was first published inside your date range.
  • Updated means an older item was modified inside your date range.
  • Data is refreshed once a day by a scheduled job in this repository.
  • Save location prompting uses the File System Access API. In browsers without it, the file downloads to your default folder instead.
